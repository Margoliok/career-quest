# 3-қосымша. Сауалнамалар

**Кесте Қ3.1 – Жеке даму жоспарын сарапшылық бағалау сауалнамасы**

Нұсқаулық: әр профиль үшін A және B жоспарларын (қай жоспарды жүйе жасағаны көрсетілмейді) төмендегі өлшемдер бойынша 1-ден 5-ке дейін бағалаңыз (1 — мүлдем сәйкес емес, 5 — толық сәйкес).

| № | Өлшем | Сипаттамасы | Балл (1–5) |
|---|---|---|---|
| 1 | Сәйкестік | Жоспардағы дағдылар қызметкердің мақсатты рөліне және қазіргі деңгейіне сәйкес келеді | |
| 2 | Орындалуы | Жоспар 30/60/90 күн ішінде жұмыстан қол үзбей орындауға болатындай нақты | |
| 3 | Түсіндірменің айқындығы | Неге дәл осы дағдылар мен рет таңдалғаны түсінікті | |

Ескерту – автор құрастырған.

**Кесте Қ3.2 – SUS сауалнамасы (қазақ тілінде)**

Әр тұжырымға келісу деңгейін белгілеңіз: 1 — мүлдем келіспеймін … 5 — толық келісемін.

| № | Тұжырым | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 1 | Мен бұл жүйені жиі қолданғым келеді деп ойлаймын. | | | | | |
| 2 | Жүйе қажетсіз күрделі деп ойлаймын. | | | | | |
| 3 | Жүйені пайдалану оңай деп ойлаймын. | | | | | |
| 4 | Бұл жүйені пайдалану үшін маған техникалық маманның көмегі қажет болады. | | | | | |
| 5 | Жүйенің әртүрлі функциялары жақсы біріктірілген. | | | | | |
| 6 | Жүйеде сәйкессіздіктер тым көп. | | | | | |
| 7 | Көпшілік бұл жүйені тез үйреніп алады деп ойлаймын. | | | | | |
| 8 | Жүйені пайдалану өте ыңғайсыз. | | | | | |
| 9 | Жүйені пайдалану кезінде өзімді сенімді сезіндім. | | | | | |
| 10 | Жүйемен жұмыс істей бастау үшін көп нәрсені үйренуім керек болды. | | | | | |

Ескерту – Brooke (1996) SUS шкаласының автор жасаған қазақша аудармасы; есептеу (12) формула бойынша.
